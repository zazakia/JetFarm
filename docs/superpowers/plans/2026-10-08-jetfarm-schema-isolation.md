# JetFarm Schema Isolation (`public` → `jetfarm_db`) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Move every JetFarm-owned table and its satellite objects from the shared `public` schema into a dedicated `jetfarm_db` schema on the self-hosted Hetzner Supabase instance, with backup, verification, and rollback defined at every stage.

**Architecture:** Metadata-only cutover (Approach A from the spec): an audited move list is applied with `ALTER … SET SCHEMA` inside one transaction, PostgREST additionally exposes `jetfarm_db` (keeping `public` as the default for other apps), and the JetFarm client pins itself to the new schema through a single env-driven option on the existing `supabase` singleton. No rows move; every stage's rollback is the inverse `SET SCHEMA` list.

**Tech Stack:** Expo/React Native + WatermelonDB SyncService, `@supabase/supabase-js` ^2.106 (supports `db.schema`), self-hosted Supabase on Hetzner VPS (containers `supabase-db`, `supabase-rest`; SSH alias `hetzner`), PostgreSQL accessed as `supabase_admin` (the `postgres` role is not superuser — proven 2026-10-08), Node 24 (`node --test` available), Jest via jest-expo for app code.

**Spec:** `docs/superpowers/specs/2026-10-08-jetfarm-schema-isolation-design.md` (commit `4deaef0`)

## Global Constraints

- Never delete, alter, or move any object belonging to other apps (`crm_*`, `meatshopanti_*`, `vw_bir_*`, healthcare/job tables, …). Objects outside the audited JetFarm move list must remain in `public` unchanged.
- `deploy_schema_migrations` (shared cross-app ledger) stays in `public` forever.
- `PGRST_DB_SCHEMAS` keeps `public` as the FIRST entry (default schema for other apps). New value: `public,storage,graphql_public,jobflow,jetfarm_db`.
- All production SQL runs as `supabase_admin`: `ssh hetzner "docker exec -i supabase-db psql -U supabase_admin -d postgres -v ON_ERROR_STOP=1 -f -"` (stream file via stdin) or `-tAc "<query>"`.
- Never print secret values. `.env.hetzner` (repo) and `/home/deploy/apps/supabase/.env` (VPS) may only be touched by the OPERATOR; the agent may check the presence of a named variable with `grep -c` (no value output). The one exception, sanctioned because it is non-secret routing config: the agent may read/verify the `PGRST_DB_SCHEMAS` line; the value edit itself is an OPERATOR step.
- Risk tier for `src/database/` changes (Task 3): `npm run lint`, `npx tsc --noEmit`, related Jest suites, `npm run check:sync`, `npm run audit:crud:gate`; evidence files under `tmp/systematic-test-matrix/`.
- Human-only actions stay human-only except where the operator's "plan and execute … each stage with backup and rollback" instruction explicitly covers them: Tasks 6–8 each start with an in-chat OPERATOR GO checkpoint; the agent pauses there.
- Currency/branding/other project conventions unchanged; scripts live in `scripts/`, tests beside their subject, evidence in `tmp/systematic-test-matrix/`, nothing new at repo root.
- The maintenance window runs Tasks 4→5→6→7→8 in that order. No task after Task 5 (audit freeze) may change the move list; if fresh evidence contradicts it, stop and re-plan.

```js
// Pure logic + SQL emitters for isolating JetFarm tables from `public` into `jetfarm_db`.
// Tests: node --test scripts/__tests__/jetfarmSchemaPlan.test.mjs
// Design: docs/superpowers/specs/2026-10-08-jetfarm-schema-isolation-design.md

export const ALWAYS_EXCLUDE = new Set(['deploy_schema_migrations']);
const MOVE_TABLE = /^[a-z][a-z0-9_]*$/;

export function parseCreateTableNames(sqlSources) {
    const names = new Set();
    const re = /^\s*create\s+table\s+(?:if\s+not\s+exists\s+)?(?:public\.)?([a-z_][a-z0-9_]*)\s*[i(]/gim;
    for (const src of sqlSources) {
        let m;
        while ((m = re.exec(src))) names.add(m[1].toLowerCase());
    }
    return names;
}

export function buildMovePlan(inputs) {
    const {
        version, liveTables, migrationTables, codeTables, fkEdges = [],
        liveSequences = [], typeUsage = [], viewAudit = [], functionAudit,
    } = inputs;
    const live = new Set(liveTables.map(t => t.toLowerCase()));
    const claimed = new Set([...migrationTables, ...codeTables].map(t => t.toLowerCase()));
    let moving = new Set([...claimed].filter(t => live.has(t) && !ALWAYS_EXCLUDE.has(t) && MOVE_TABLE.test(t)));

    // Safety valve: exclude any table another app's (non-moving) table has an FK into,
    // then re-check transitively so a moving table never depends on an excluded one silently.
    const excludedTables = [];
    for (let pass = 0; pass < 2; pass++) {
        for (const table of [...moving]) {
            const inbound = fkEdges.filter(e => e.toTable === table && !moving.has(e.fromTable));
            if (inbound.length) {
                moving.delete(table);
                excludedTables.push({ table, reason: `inbound FK from ${[...new Set(inbound.map(e => e.fromTable))].join(', ')}` });
            }
        }
    }

    const sequences = liveSequences.filter(s => moving.has(s.ownedTable.toLowerCase()));

    const typeUsers = new Map();
    for (const { type, relation } of typeUsage) {
        if (!typeUsers.has(type)) typeUsers.set(type, new Set());
        typeUsers.get(type).add(relation);
    }
    const types = [...typeUsers.entries()]
        .filter(([, rels]) => [...rels].every(r => moving.has(String(r).toLowerCase())))
        .map(([type]) => type)
        .sort();

    const views = viewAudit.filter(v => v.jetFarmCreated && live.has(v.view)).map(v => v.view).sort();

    const externalByFn = new Map();
    for (const ref of functionAudit.externalRefs || []) {
        const internal = !ref.relation.includes('.') && moving.has(String(ref.relation).toLowerCase());
        if (!internal) {
            if (!externalByFn.has(ref.fn)) externalByFn.set(ref.fn, []);
            externalByFn.get(ref.fn).push(ref.relation);
        }
    }
    const byName = new Map(functionAudit.functions.map(f => [f.name, f]));
    const created = new Set(functionAudit.jetFarmCreatedNames);
    const codeRef = new Set(functionAudit.codeReferencedNames);
    const functionsToMove = [];
    const functionsToCopy = [];
    const keptFunctions = [];
    for (const name of [...created].sort()) {
        const fn = byName.get(name);
        if (!fn) continue;
        const ext = externalByFn.get(name);
        if (ext) {
            if (ext.some(r => r.includes('.'))) {
                keptFunctions.push({ name, reason: `external-ref:${ext.find(r => r.includes('.'))}` });
            }
            functionsToCopy.push(fn); // shared but ours: leave original, add a copy
            continue;
        }
        functionsToMove.push({ name: fn.name, sig: fn.sig });
    }
    for (const name of [...codeRef].sort()) {
        const fn = byName.get(name);
        if (!fn) continue;
        if (created.has(name) && !externalByFn.has(name)) continue; // moved already
        if (functionsToCopy.some(f => f.name === name)) continue;
        functionsToCopy.push(fn);
    }

    return {
        version,
        schema: 'jetfarm_db',
        tables: [...moving].sort(),
        sequences: sequences.sort((a, b) => a.sequence.localeCompare(b.sequence)),
        types,
        views,
        functionsToMove,
        functionsToCopy,
        excludedTables,
        keptFunctions,
    };
}

export function emitIsolationSql(plan) {
    const lines = [];
    lines.push(`-- ${plan.version}_jetfarm_schema_isolation.sql`);
    lines.push(`-- Generated by scripts/jetfarmSchemaPlan.mjs --emit from the audited live catalog.`);
    lines.push(`-- Metadata-only move of ${plan.tables.length} JetFarm tables from public into ${plan.schema}.`);
    lines.push(`-- Run as supabase_admin. Rollback: scripts/jetfarm-schema-rollback.sql`);
    lines.push('BEGIN;');
    lines.push(`CREATE SCHEMA IF NOT EXISTS ${plan.schema} AUTHORIZATION supabase_admin;`);
    lines.push(`GRANT USAGE ON SCHEMA ${plan.schema} TO anon, authenticated, service_role;`);
    lines.push(`ALTER DEFAULT PRIVILEGES FOR ROLE supabase_admin IN SCHEMA ${plan.schema} GRANT SELECT, INSERT, UPDATE, DELETE ON TABLES TO anon, authenticated, service_role;`);
    lines.push(`ALTER DEFAULT PRIVILEGES FOR ROLE supabase_admin IN SCHEMA ${plan.schema} GRANT USAGE, SELECT ON SEQUENCES TO anon, authenticated, service_role;`);
    lines.push(`ALTER DEFAULT PRIVILEGES FOR ROLE supabase_admin IN SCHEMA ${plan.schema} GRANT EXECUTE ON FUNCTIONS TO anon, authenticated, service_role;`);
    for (const t of plan.types) lines.push(`ALTER TYPE public.${t} SET SCHEMA ${plan.schema};`);
    for (const t of plan.tables) lines.push(`ALTER TABLE public.${t} SET SCHEMA ${plan.schema};`);
    for (const s of plan.sequences) lines.push(`ALTER SEQUENCE public.${s.sequence} SET SCHEMA ${plan.schema};`);
    for (const v of plan.views) lines.push(`ALTER VIEW public.${v} SET SCHEMA ${plan.schema};`);
    if (plan.functionsToMove.length) {
        const list = plan.functionsToMove.map(f => `'${f.name}'`).join(', ');
        lines.push(`DO $$`);
        lines.push(`DECLARE r record; BEGIN`);
        lines.push(`  FOR r IN SELECT p.oid::regprocedure AS sig FROM pg_proc p JOIN pg_namespace n ON n.oid = p.pronamespace`);
        lines.push(`             WHERE n.nspname = 'public' AND p.proname = ANY(ARRAY[${list}]) LOOP`);
        lines.push(`    EXECUTE format('ALTER FUNCTION %s SET SCHEMA ${plan.schema}', r.sig);`);
        lines.push(`  END LOOP; END $$;`);
    }
    for (const f of plan.functionsToCopy) {
        const copy = f.def.replace(/CREATE OR REPLACE FUNCTION public\./, `CREATE OR REPLACE FUNCTION ${plan.schema}.`);
        lines.push(`-- additive copy of shared function ${f.sig} (original stays in public)`);
        lines.push(copy);
    }
    lines.push('COMMIT;');
    lines.push(`NOTIFY pgrst, 'reload schema';`);
    return lines.join('\n') + '\n';
}

export function emitRollbackSql(plan) {
    const lines = [];
    lines.push(`-- Emergency inverse of ${plan.version}_jetfarm_schema_isolation.sql — moves objects back, drops nothing.`);
    lines.push('BEGIN;');
    for (const f of plan.functionsToMove) lines.push(`-- undo function move: ${f.sig}`);
    if (plan.functionsToMove.length) {
        const list = plan.functionsToMove.map(f => `'${f.name}'`).join(', ');
        lines.push(`DO $$`);
        lines.push(`DECLARE r record; BEGIN`);
        lines.push(`  FOR r IN SELECT p.oid::regprocedure AS sig FROM pg_proc p JOIN pg_namespace n ON n.oid = p.pronamespace`);
        lines.push(`             WHERE n.nspname = '${plan.schema}' AND p.proname = ANY(ARRAY[${list}]) LOOP`);
        lines.push(`    EXECUTE format('ALTER FUNCTION %s SET SCHEMA public', r.sig);`);
        lines.push(`  END LOOP; END $$;`);
    }
    for (const v of plan.views) lines.push(`ALTER VIEW ${plan.schema}.${v} SET SCHEMA public;`);
    for (const s of plan.sequences) lines.push(`ALTER SEQUENCE ${plan.schema}.${s.sequence} SET SCHEMA public;`);
    for (const t of plan.tables) lines.push(`ALTER TABLE ${plan.schema}.${t} SET SCHEMA public;`);
    for (const t of plan.types) lines.push(`ALTER TYPE ${plan.schema}.${t} SET SCHEMA public;`);
    for (const f of plan.functionsToCopy) lines.push(`DROP FUNCTION IF EXISTS ${plan.schema}.${f.sig};`);
    lines.push('COMMIT;');
    lines.push(`NOTIFY pgrst, 'reload schema';`);
    return lines.join('\n') + '\n';
}
```

```js
export function collectRepoInputs(repoRoot) {
    const read = p => fs.existsSync(p) ? fs.readFileSync(p, 'utf8') : '';
    const migDir = path.join(repoRoot, 'supabase', 'migrations');
    const migrationSources = fs.readdirSync(migDir).filter(f => f.endsWith('.sql')).map(f => read(path.join(migDir, f)));
    const migrationTables = parseCreateTableNames(migrationSources);
    const viewCreatedNames = new Set();
    const fnCreatedNames = new Set();
    for (const src of migrationSources) {
        for (const m of src.matchAll(/^\s*create\s+(?:or\s+replace\s+)?view\s+(?:if\s+not\s+exists\s+)?(?:public\.)?([a-z_][a-z0-9_]*)/gim)) viewCreatedNames.add(m[1].toLowerCase());
        for (const m of src.matchAll(/^\s*create\s+(?:or\s+replace\s+)?function\s+(?:public\.)?([a-z_][a-z0-9_]*)/gim)) fnCreatedNames.add(m[1].toLowerCase());
    }
    const contract = JSON.parse(read(path.join(repoRoot, 'src', 'services', 'syncTableContract.json')) || '{}');
    const remoteNames = new Set();
    for (const entry of [...(contract.coreTables || []), ...(contract.configTables || [])]) {
        remoteNames.add(typeof entry === 'string' ? entry : (entry.remote || entry.name));
    }
    // literal .from('x') call sites anywhere in client code
    const codeTables = new Set([...migrationTables]);
    for (const dir of ['src', 'app']) {
        const stack = [path.join(repoRoot, dir)];
        while (stack.length) {
            const cur = stack.pop();
            if (!fs.existsSync(cur)) continue;
            for (const e of fs.readdirSync(cur, { withFileTypes: true })) {
                const fp = path.join(cur, e.name);
                if (e.isDirectory()) { if (!['node_modules', '__tests__', '__mocks__'].includes(e.name)) stack.push(fp); continue; }
                if (!/\.(ts|tsx)$/.test(e.name)) continue;
                const src = read(fp);
                for (const m of src.matchAll(/\.from\(\s*['"]([a-z_][a-z0-9_]*)['"]/g)) codeTables.add(m[1]);
            }
        }
    }
    const fnCodeRefs = [];
    // re-scan for rpc names
    const rpcRe = /\.rpc\(\s*['"]([a-z_][a-z0-9_]*)['"]/g;

    for (const n of remoteNames) if (n) codeTables.add(n);
    codeTables.delete('deploy_schema_migrations');
    return { migrationTables, codeTables, viewCreatedNames, fnCreatedNames, fnCodeRefs: [...new Set(fnCodeRefs)] };
```
